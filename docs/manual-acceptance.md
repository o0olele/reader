## A. F1 · 九组快捷键（§6.1 #8）

对照原型 `desktop-ui.html:2757–2776`。**每组都要额外验证「焦点在输入框内时不触发」**（原型 :2759 只跳过 input/textarea，本实现还跳过 select 与 contenteditable）。

| # | 按键 | 步骤 | 期望 | 实测 | 结论 |
| ---: | --- | --- | --- | --- | --- |
| A1 | `Esc` | ① `Ctrl+K` 打开面板后按 `Esc` ② 在首页无弹层时按 `Esc` | ① 面板关闭 ② 无副作用（不导航、不改主题） | | |
| A2 | `Ctrl+B` | 在首页按一次、再按一次；然后**重启应用** | rail 在 **220px ↔ 56px** 间切换；重启后保持上次状态（`localStorage['rail-extended']`） | | |
| A3 | `Ctrl+K` | 打开面板 → 输入一本书架里的书名 → 回车 | 出结果；回车跳到书架或阅读器 | | |
| A4 | `D` | 在首页按 `D`；再在书架搜索框内按 `D` | 主题浅/深切换；**输入框内按 `D` 只输入字符 d，不切主题** | | |
| A5 | `1`–`5` | 依次按 1…5 | 首页 / 书架 / 发现 / RSS / 我的（与原型 :2768 一致）；输入框内按数字**不导航** | | |

| A8 | `T` | 阅读器内按 | 目录侧栏开关；输入框内按 `T` 不触发 | | |
| A9 | `F` | 阅读器内按 | 沉浸模式开关（见 C9） | | |

## C. F3 · 阅读器运行时几何（本次新写，最需要人眼）

### C0 · 触发条件先算清楚

双栏只在**正文内容宽 ≥ 760px 且 `window.innerHeight` ≥ 820px** 时出现
（`useReaderPaging.syncPageMetrics`，对应原型 `:870–885`）。
正文内容宽 = `窗口宽 − rail − 目录(288) − 面板(320) − 2×页边距(默认 32)`。

| 窗口宽 | rail | 目录 | 面板 | 正文内容宽 | 预期 |
| ---: | --- | --- | --- | ---: | --- |
| 1280 | 展开 220 | 关 | 关 | 996 | **双栏** |
| 1280 | 展开 220 | 开 | 关 | 708 | 退回单栏 |
| 1280 | 收起 56 | 关 | 关 | 1160 | **双栏** |
| 1500 | 展开 220 | 开 | 关 | 928 | **双栏** |
| 1500 | 展开 220 | 开 | 开 | 608 | 退回单栏 |
| 1700 | 展开 220 | 开 | 开 | 808 | **双栏** |

> 高度门槛量的是 `window.innerHeight`。若窗口带系统边框，**窗口高度需 ≈ 860px 以上**才稳过 820。

### C10 · 预下载附近章节（对位 `ReadBook.preDownload()`）

前置：`#/settings/cache` 里把「预下载章节数」保持在默认 10；用一本**真实在线书**（见 D4）。
缓存章数以设置页「正文缓存」的「N 章」为准，日志看 `%APPDATA%\com.reader.desktop\logs\reader-desktop.log`
（`target: reader`）。**自动化的部分只有窗口规则**（`cargo test prefetch`，11 条），下面全是真机项。

| # | 步骤 | 期望 | 实测 | 结论 |
| ---: | --- | --- | --- | --- |
| C10.1 | 打开第 10 章，记下打开瞬间的缓存章数，静置 10 秒 | 缓存章数按「向前 10 + 向后至多 5」增长；日志出现 `chapter prefetch finished`（`planned` 与实际新增一致） | | |
| C10.2 | 打开第 1 章 | 向前不越界（目录头即停）；向后为空，不报错 | | |
| C10.3 | 打开最后一章 | 向前为空；向后至多 5 章 | | |
| C10.4 | 连续快速点「下一章」8 次 | 只有最后一次窗口继续（旧窗口日志 `chapter prefetch cancelled`）；同一域名同时最多 2 个请求，不出现卡顿 | | |
